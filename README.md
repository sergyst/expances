# הכספים של העסק

אפליקציה לניהול פיננסי של עסק קטן — הוצאות, הכנסות, קבלות ותקציב.
הכל בקובץ HTML אחד: לחיצה כפולה על `index.html` והיא נפתחת בדפדפן, בלי התקנה ובלי אינטרנט.

## מה יש בפנים

- **דשבורד** — הכנסות, נכנס בפועל, הוצאות, רווח, ויתרת החשבון בתחילת החודש ובסופו. לכל מספר חץ מגמה מול החודש הקודם.
- **גרף שלושה חודשים** — החודש שעבר, החודש הזה והבא, זה לצד זה.
- **פילוח הוצאות** — טבעת עם שם וסכום על כל קטגוריה.
- **תשלומים** — בהוצאות נוצרת שורה לכל חודש; בהכנסות ההכנסה נרשמת במלואה ביום העסקה והכסף נכנס חודש אחרי חודש.
- **קבלות** — צילום או PDF לכל רישום, עם מתג בין קבלות הוצאות לקבלות הכנסות.
- **תקציב** — תקרה לכל קטגוריה, בשקלים או באחוז מההכנסה של החודש שעבר.
- **ייצוא** — אקסל לרואה חשבון, גיבוי מלא, והעתקה למחשב אחר בקובץ אחד.

## איפה הנתונים

בדפדפן שבו נפתחה האפליקציה (`localStorage`), ולא בתוך הקובץ ולא בשום שרת.
לכן: לעבוד תמיד באותו דפדפן, ולעשות **גיבוי לקובץ** מדי פעם.

להעברה למחשב אחר — ☰ ← "העתקה למחשב אחר": יורד קובץ HTML אחד שכולל גם את האפליקציה וגם את הרישומים.

## פיתוח

אין שלב בנייה ואין תלויות. עורכים את `index.html` ומרעננים את הדפדפן.
